# Upstream Methodology

This skill is a Codex-focused adaptation inspired by the Superpowers project:

- Repository: https://github.com/obra/superpowers
- Author: Jesse Vincent and contributors
- License: MIT
- Upstream concepts reviewed: brainstorming, planning, test-driven development, systematic debugging, code review, and verification before completion

The adaptation intentionally condenses the upstream multi-skill plugin into one portable workflow and changes platform-specific instructions to match Codex. User instructions and Codex system constraints always take precedence.

The upstream project remains the canonical source for its complete skill library and installation options.
